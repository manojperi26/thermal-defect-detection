# ThermoRecon: Unsupervised Thermal Defect Detection Using Autoencoders

ThermoRecon is a **simulation-only research prototype** for unsupervised anomaly detection of subsurface defects in thermal images. The system trains a convolutional autoencoder **only on defect-free synthetic data** and uses reconstruction error to detect and localize simulated defects. The synthetic thermal data is generated using a 3D finite-difference heat-diffusion simulator inspired by concepts from active infrared thermography for non-destructive testing. A simple non-learned polynomial-fitting method is used as a baseline.

> **Simulation-only proof of concept:** All experiments in this repository use synthetic data generated by the included physics simulator. No real thermal-camera dataset is used, and the results should not be interpreted as validation on real-world thermal imaging.

## Key Findings

- Overall, the autoencoder and polynomial baseline are **about equal in image-level discrimination**: AE AUC is **0.829**, while the baseline AUC is **0.825**.
- The AE has higher global F1 (**0.592 vs. 0.462**) and performs better at very low false-positive rates, while the baseline is slightly better around **FPR 0.4–0.7** on the ROC curve.
- Shallow simulated defects are substantially easier to detect. At the 99th-percentile threshold, depth 1 is detected well by both methods, while neither method successfully thresholds depth 3 or 4 defects.
- The baseline produces better IoU at depth 2 (**0.530 vs. 0.263**), showing that better image-level detection does not necessarily translate into better localization.
- The AE is less robust to added noise in this experiment. With test noise increased from **0.28 to 2.8 °C standard deviation**, AE AUC decreases from **0.83 to 0.61**, while the baseline decreases from **0.83 to 0.76**.
